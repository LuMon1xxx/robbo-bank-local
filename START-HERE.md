# ЗАПУСК-ИНСТРУКЦИЯ (fallback, пока нет exe)

Если файл `RobboBank.exe` уже собран — запускайте его двойным кликом и дальше читайте `README-УЧИТЕЛЮ.md`.
Если exe нет на этой машине — запуск через Node (2 минуты настройки, один раз):

## 1. Установить Node LTS (один раз)
1. Открыть https://nodejs.org
2. Скачать LTS (долгосрочная поддержка) для Windows x64, установить «Далее-Далее».
3. Проверить: открыть PowerShell и выполнить `node --version` (должно показать v22/v24).

## 2. Первый запуск банка
1. Распаковать папку `robbo-bank-local` (в ней должны быть `package.json`, `src`, `dist`).
2. Двойной клик по `start-bank.bat`:
   - при первом запуске сам сделает `npm i`;
   - запустит dev-сервер на http://localhost:1420;
   - сам откроет браузер.
3. Если браузер не открылся — вручную открыть http://localhost:1420

## Ручной вариант (без bat)
```
npm i
npm run dev -- --port 1420
```
Открыть http://localhost:1420

## 3. Готовая сборка без сервера
Папка `dist/` уже собрана (`npm run build`).
Можно показать её через любой статический сервер, но для учителя проще `start-bank.bat` выше.

## 4. Проверка что всё живо
- `npm test` → должно быть 7 файлов / 65 тестов, все зелёные.
- `npm run build` → `dist/index.html` + `dist/assets/*` обновляются без ошибок TypeScript.
