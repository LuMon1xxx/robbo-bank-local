# 🏦 Роббо Банк (локально) — инструкция учителю

Всё хранится **только на этом компьютере** (браузер / файл `robbo.db` в exe-версии). Интернет не нужен, кроме первой установки.

## 1. Как запустить

**Если есть exe:** двойной клик по `RobboBank.exe` → открывается окно «РоббоБанк». Всё.

**Если exe нет (fallback):** двойной клик по `start-bank.bat` → сам откроет браузер на http://localhost:1420
Не закрывайте чёрное окно, пока работаете. В конце закройте его (Ctrl+C).

Сверху выберите своё имя: **Учитель 1 / Учитель 2** (подставляется автором операций).

## 2. Начислить за 2 клика ⚡

1. Вкладка **Ученики** → найдите ученика (поиск сверху).
2. Клик 1: кнопка **⚡** в строке ученика → окно «Быстрая операция».
3. Клик 2: чип причины, например **«За занятие +4»** или **«Активность +5»**.
   - Нужна другая сумма? Впишите в поле «Своя сумма» перед кликом по чипу.
4. Баланс обновится сразу. Всплывёт тост с кнопкой **Отменить** (Undo) — отмена той же операции.

Полная операция (со списанием и комментарием): кнопка **📝** в строке ученика.

## 3. Начислить всей группе (bulk)

1. Вкладка **Ученики** (или **Группы**) → поставьте галочки ✔ нужным ученикам.
2. Внизу появится панель **«Выбрано: N · Начислить N × сумма»**.
3. Выберите **Причину** из списка, при желании впишите сумму каждому.
4. Нажмите **Подтвердить**.
   - Всё или никому (атомарно): если хоть один ученик «битый» — никому не начислится и увидите кому отказано.

## 4. Импорт учеников из Excel

1. Вкладка **Ученики** → кнопка **«Импорт Excel»**.
2. Выберите файл `.xlsx` с заголовками: **Фамилия | Имя | Отчество | Группа | Телефон | Дата рождения**.
3. Увидите «Распознано строк: N. Первые 5: …» → нажмите **Импортировать**.
4. Отчёт покажет «добавлено N, ошибок M» (например, группа длиннее 10 символов — та строка отклоняется, остальные добавляются).

## 5. Отчёт, сверка, выгрузка

Вкладка **Отчёты**:
- Период: **Сегодня / Неделя (7 дней) / Месяц / Всё время** (время — Москва).
- Кнопки **«Скачать CSV»** (открывается в Excel сразу, кириллица ок) и **«Скачать XLSX»**.
- Кнопка **«Сверить балансы»**: норма — «Расхождений нет». Если список не пуст — позовите администратора, ничего не трогайте.
- В карточке ученика — его история операций + отмена любой операции кнопкой **«Отменить»** (повторная отмена запрещена). Над историей есть **поиск** (по причине/комментарию/автору) и **фильтр по типу** (начисления/списания/отмены).

## 6. Бэкап на флешку 💾 (делайте раз в неделю!)

При каждом закрытии программа САМА тихо сохраняет автокопию (последние 10 штук).
Проверить: адресная строка проводника `%APPDATA%\ru.robbo.bank.local\backups`.

Но флешка всё равно нужна — компьютер могут украсть/сломать:
1. В верхней панели нажмите **«💾 JSON»** → скачается `robbo-backup-YYYY-MM-DD.json`.
2. Скопируйте файл на флешку / в облако.
3. Восстановление: кнопка **«📂 Restore»** → выбрать JSON → подтвердить («Текущие данные будут заменены»).

## 7. Группы

Вкладка **Группы**: создать / переименовать / удалить группу, перенести ученика («➕ в группу», «убрать из группы»).
Удаление группы учеников НЕ удаляет — у них просто очищается поле группы.

## 8. Что делать если что-то не так

| Симптом | Что делать |
|---|---|
| Начислил не тому / не ту сумму | Нажать **Отменить** в тосте сразу, либо открыть карточку ученика → найти операцию → **Отменить** |
| Кнопка «Списание» серая | У ученика баланс 0 или долг — списание недоступно. Сначала начислите или отмените начисление |
| «Недостаточно баланса» | Нельзя списать больше, чем есть. Уменьшите сумму |
| Импорт ругается на ФИО | Нужны заголовки Фамилия/Имя/Отчество в первой строке; пустые строки пропускаются |
| Восстановление не срабатывает | Файл должен быть именно нашим `robbo-backup-*.json`, не Excel. Ошибка покажет причину |
| Белый экран / не открывается | Закрыть, запустить `start-bank.bat` заново; проверить http://localhost:1420 ; убедиться что чёрное окно не закрыто |
| Браузер предлагает «запомнить пароль» | Не нужно — входов и паролей нет, только выбор учителя сверху |

Данные живут в файле базы `%APPDATA%\ru.robbo.bank.local\robbo.db` (переезжать на другой компьютер — копировать эту папку целиком или через JSON из п.6). Чистка браузера базу НЕ трогает.
